## ما لا يُنقل ولماذا

- يحتوي HTML على دالتي `loadLocal` و`saveLocal` مع استعمال `localStorage`، ويظهر فيه مسار `DB.collection(...)`؛ لا يُستخدم ذلك كمصدر بيانات أو بديل عن Supabase/RLS.
- يحتوي الكود على أسماء حقول للمستعير/الطالب وتدفق استعارة وإرجاع. لا تُنقل هذه الحقول أو النماذج أو أي بيانات أشخاص.
- لا يظهر داخل HTML فحص صريح للدور أو الصلاحية؛ لا يُعد هذا حكمًا على كود Android الأصلي غير المفحوص. تعتمد التجربة على جلسة الموقع الحالية وقواعده، وتبقي كل تغيير في الشاشة الأصلية.
- يقيّد وسم viewport التكبير عبر `maximum-scale` و`user-scalable=no`؛ لا يُعاد استخدام ذلك، وتبقى التجربة قابلة للتكبير.
- بطاقة الفهرس ليست ضمن المصدر المرجعي أو هذه التجربة؛ تظل مؤجلة إلى أن يرسل المالك تحديثها وحقولها.
