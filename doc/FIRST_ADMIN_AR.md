# تهيئة أول مسؤول للمكتبة

تُنفذ هذه الخطوات بعد تطبيق الهجرة على مشروع Supabase الجديد `borsaid-school-library` فقط. لا تنشئ حساباً أو بيانات في `amin-library`.

## 1. إنشاء حساب موظف

من لوحة Supabase للمشروع، افتح **Authentication → Users** وأنشئ/ادعُ مستخدماً بعنوان بريد المسؤول وفق سياسة الجهة. فضّل دعوة البريد أو رابط تعيين كلمة مرور ليضبطها المستخدم بنفسه؛ لا ترسل كلمة مرور مشتركة أو مؤقتة في الرسائل. لا يوجد تسجيل عام ولا كلمة مرور إدارية افتراضية. بعد رفع الموقع، اضبط عنوان إعادة التوجيه وفق `docs/PASSWORD_SETUP_AR.md`؛ الحساب الذي أكّد بريده يمكنه طلب رابط استعادة من شاشة دخول الموظفين.

## 2. إنشاء المكتبة وربط المسؤول

في **SQL Editor** شغّل أولاً هذا الاستعلام باسم رسمي تختاره المدرسة/الجهة:

```sql
insert into public.libraries (name, governorate, city, is_published)
values ('مكتبات المدارس - بورسعيد', 'بورسعيد', 'بورسعيد', false)
returning id;
```

احتفظ بمعرّف المكتبة الناتج، ثم احصل على معرّف المستخدم من صفحة Authentication → Users. شغّل التالي بعد استبدال القيمتين ببيانات المشروع الفعلية:

```sql
insert into public.library_memberships (library_id, user_id, role, status)
values (
  '<LIBRARY_UUID>'::uuid,
  '<AUTH_USER_UUID>'::uuid,
  'owner',
  'active'
);
```

لا تضع أي كلمة مرور أو مفتاح إداري في SQL أو الموقع. هذه العملية تستخدم صلاحية لوحة Supabase، ولا يملكها زائر الموقع.

## 3. إنشاء الفرع الأول

سجّل الدخول إلى لوحة الموظفين. من تبويب **الفروع** أضف اسماً وعنواناً صحيحاً؛ اترك خانة النشر غير محددة إلى حين مراجعة التفاصيل.
بعد إدخال بيانات الفرع والعناوين الحقيقية ومراجعتها، يستطيع المالك أو المسؤول فتح **الفروع → ظهور المكتبة في الفهرس العام**. لا تظهر الكتب للعامة إلا إذا أكد المالك نشر المكتبة، ونشر الفرع، ونشر العنوان والنسخة كلًّا وفق اختياره. سيطلب الموقع تأكيدًا قبل نشر المكتبة أو إخفائها.

## 4. الإعدادات اللاحقة

- قبل نشر وإعداد Edge Function للدعوات، أضف الموظفين في Authentication ثم سجّل عضويتهم يدوياً بأدوار مناسبة: `admin`, `librarian`, `circulation`, أو `reporter`. بعد نشر الدالة وضبط نطاق الموقع وإعادة التوجيه يمكن استخدام نموذج الدعوة.
- تحقّق من سياسة RLS قبل استيراد بيانات حقيقية، وابدأ بعينة بيانات غير شخصية داخل بيئة اختبار منفصلة إن توفرت.
- لا تستورد صور طلاب أو قوالب وجه/بصمة. سجلات المستعيرين وأرقام العضوية بيانات داخلية لا تظهر في الفهرس العام.
- لا تستقبل المكتبة طلبات تبادل لمجرد نشر عنوانها أو فروعها؛ فعّل خيار المشاركة صراحةً من تبويب الفروع إذا وافقت الجهة على ذلك.
- اختبر حساباً من مكتبة أخرى وحساباً غير عضو للتأكد من منع عبور المستأجرات.
- راجع خيارات النسخ الاحتياطي والاستعادة في Supabase؛ تصدير CSV من الواجهة ليس بديلاً عن نسخة قاعدة بيانات كاملة.
- Gemini غير مفعّل افتراضياً؛ راجع `docs/GEMINI_SETUP_AR.md` إذا تقرر إضافته لاحقاً، ولا تضع مفتاحه في المستودع أو واجهة المتصفح.
