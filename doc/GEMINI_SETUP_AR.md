# إعداد مساعد Gemini

## الحالة في المصدر المحلي

الواجهة تحتوي مساعدًا للمؤشرات الإجمالية فقط واختيارًا للنموذج. وظيفة `library-assistant` تقرأ الأعداد بعد التحقق من جلسة Supabase وعضوية المكتبة، ولا تقبل أو ترسل أسماء الطلاب أو المستعيرين أو أرقام العضوية أو بيانات الإعارة والزيارة. المفتاح لا يدخل في الصفحة ولا يُخزّن في `localStorage` أو Git.

اختيار النموذج في لوحة المساعد يُحفظ على **هذا المتصفح فقط**، ويرسل اسم النموذج المسموح به مع نوع الملخص. الاختيارات الحالية وفق قائمة النماذج الرسمية:

- `gemini-3.5-flash-lite` — الافتراضي الأخف.
- `gemini-3.8-flash` — خيار أعلى قدرة.

راجع [قائمة نماذج Gemini الرسمية](https://ai.google.dev/gemini-api/docs/models) قبل تغيير القائمة مستقبلًا.

## ما يلزم لتفعيله لاحقًا

1. في مشروع Supabase الصحيح `eahptkwvjcnixlzlyznh` افتح **Project Settings → Edge Functions → Secrets**، وأضف `GEMINI_API_KEY` كسرّ. لا ترسله في المحادثة أو SQL أو GitHub أو ملف الواجهة.
2. أضف `APP_ORIGIN` بالقيمة `https://selim306306.github.io` — هذا هو أصل الصفحة، **من دون** المسار `/borsaid-school-library/` أو شرطة أخيرة. يجب أن يطابق ترويسة `Origin` التي يرسلها المتصفح.
3. اختياريًا اضبط `GEMINI_MODEL=gemini-3.5-flash-lite` كقيمة افتراضية خادمية؛ الطلبات من الواجهة تستخدم الاختيار المحلي المسموح به. لا يقبل الخادم إلا النموذجين المدرجين أعلاه.
4. بعد مراجعة تغييرات المستودع ونشر الملفات التي يعتمد عليها الموقع، انشر الوظيفة إلى مشروع Supabase بموافقة مالك الحساب. مثال CLI: `supabase functions deploy library-assistant --project-ref eahptkwvjcnixlzlyznh`.
5. أبقِ `verify_jwt = true`؛ الإعداد المحلي موجود في `supabase/config.toml`. لا تستخدم خيار تعطيل التحقق. اختبر بحساب موظف مصادق عليه ومن أصل الموقع الصحيح.
6. قبل إتاحته فعليًا، ضع حدودًا للاستخدام والتكلفة ومراقبة للفشل. الوظيفة لا تعدّل بيانات المكتبة، ولا تعتبر إجابة النموذج أمرًا نافذًا.

توفر Supabase متغيرات البيئة الأساسية للوظيفة مثل `SUPABASE_URL` و`SUPABASE_ANON_KEY`. لا تحتاج وظيفة المساعد إلى `service_role`.

## حدود الخصوصية والتشغيل

- ترسل الواجهة `library_id` ونوع الملخص ومعرّف النموذج فقط؛ الوظيفة تتحقق من العضوية ثم تحسب مؤشرات مجمّعة.
- لا تُرسل بيانات أشخاص أو عناوين كتب أو سجلات فردية إلى Gemini.
- الإخراج اقتراح للموظف فقط؛ لا يغيّر أو ينشر العناوين أو الفروع أو الإعارات تلقائيًا.
- رسالة «إعداد الخادم ناقص» تعني عادةً أن الوظيفة غير منشورة أو أن السر أو `APP_ORIGIN` غير مضبوط. المفتاح لا يُدخل في شاشة الموقع.
