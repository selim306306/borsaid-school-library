# تعيين كلمة مرور حساب الموظف

توفّر الواجهة `set-password.html` لاستقبال روابط دعوة Supabase وروابط استعادة كلمة المرور، والتحقق من جلسة الرابط قبل إرسال كلمة المرور الجديدة إلى Supabase Auth. لا تحفظ الصفحة كلمة المرور في الموقع أو في مستودع الملفات. المفتاح الموجود في JavaScript من نوع **publishable** ومخصص للمتصفح؛ لا تضف `service_role` أو أي كلمة مرور/رمز وصول إلى المصدر.

## إعداد إعادة التوجيه بعد رفع تحديث الموقع

بعد أن يرفع مالك المستودع الملفات إلى GitHub Pages:

1. افتح مشروع Supabase `eahptkwvjcnixlzlyznh` ثم **Authentication → URL Configuration**.
2. أضف العنوان التالي حرفياً إلى قائمة **Redirect URLs** المسموح بها:
   `https://selim306306.github.io/borsaid-school-library/set-password.html`
3. إذا كانت دعوات الموظفين تُرسل عبر Edge Function `invite-library-member`، اضبط سرّ الوظيفة `AUTH_REDIRECT_URL` على العنوان نفسه ثم أعد نشر الوظيفة. لا تضع قيمة هذا الإعداد السرية في ملفات الموقع.
4. لدعوة مستخدم من لوحة Supabase، استخدم رابط التعيين أعلاه كعنوان إعادة التوجيه إذا كانت واجهة الدعوة تسمح به. إن كانت الدعوة تستخدم `Site URL` الافتراضي، حدّث قالب رسالة الدعوة/إعداد إعادة التوجيه بالطريقة المعتمدة في Supabase قبل إرسالها.

## للحساب الذي أكّد بريده مسبقاً

لا يلزم إنشاء الحساب من جديد. بعد رفع الملفات والسماح بعنوان إعادة التوجيه، افتح **دخول الموظفين** في الموقع، أدخل بريد الحساب، ثم اختر **«نسيت كلمة المرور أو لم أعيّنها بعد؟»**. ستصل رسالة استعادة، ويفتح رابطها هذه الصفحة لتعيين كلمة المرور. تعرض الواجهة رسالة عامة عند طلب الرابط لتقليل كشف ما إذا كان البريد مسجلاً.

إذا كان رابط الدعوة/الاستعادة قديماً أو انتهت صلاحيته، اطلب رابطاً جديداً. لا تعِد استخدام الرابط الذي أعاد المستخدم إلى `localhost:3000`.

## حدود التغيير

هذا التحديث يضيف الملفات محلياً فقط. يجب على مالك المستودع مراجعة التغييرات ورفعها بنفسه؛ لا يحدث نشر إلى GitHub تلقائياً. لا تغيّر هذا الإعداد عضوية المالك أو صلاحيات المكتبة.
