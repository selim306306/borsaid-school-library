# لمسة بصرية للمكتبة المدرسية الرقمية

أضيفت طبقة تنسيق `reader-theme.css` بعد التنسيقات الحالية. التغيير خاص بالمظهر؛ لم تتغير ملفات JavaScript أو قواعد البيانات أو صلاحيات الوصول أو الصور والشعارات أو المحتوى وترتيب الأقسام.

## الفروق المرئية

خلفية فاتحة محايدة، أبيض واضح للبطاقات، بترولي أعمق للعناوين والأزرار والتبويب المختار، وتقليل تراكب التدرجات والظلال. تتمايز عائلات الأقسام بهدوء: أخضر للفهرس، رملي للمدارس، بحري للقراءة، وأزرق للأخبار والبحث. بقيت مختصرات المساعدين والأخبار الواردة في مواضعها، مع تحديث ألوانها فقط. حافظنا على الطباعة العربية وأحجامها وكثافة الهاتف؛ تحسين التسلسل البصري هنا من التباين والأوزان والألوان لا تكبير العناصر.

## الاختبار

- نجحت الاختبارات الآلية كاملة: 220 اختبارًا بلا فشل.
- فحص Playwright التبويبات العامة السبعة بعروض 360 و390 و768 و1440 بكسل: 28 حالة بلا تجاوز أفقي، مع تبويب عام مختار واحد.
- على هاتف بعرض 390 بكسل بقي طول الرئيسية 4474 بكسل، وارتفاعات المقدمة والمساعدين والأخبار متطابقة عند تشغيل الطبقة وإيقافها على الصفحة نفسها.
- نجح انتقال بحث الرئيسية إلى الفهرس، وفتح/إغلاق المساعد ودخول الموظفين، وفتح إفصاح الخصوصية، وظهور إطار التركيز 3 بكسل. لم نرسل أسئلة ولم ندخل حسابات أو نغيّر سجلات.
- عند تفضيل تقليل الحركة، مدة الانتقال صفر والتمرير غير متحرك.
- نسب التباين المحسوبة للأزواج الرئيسية الجديدة: أبيض/بترولي للتبويب 7.38:1، نص العنوان/أبيض 11.93:1، النص الثانوي/الخلفية 5.56:1. هذه قياسات للأزواج المحددة وليست تدقيق إتاحة شاملًا لكل الموقع.

## المراجع والقيود

رُوجعت إرشادات CSS عبر Context7 من توثيق [MDN](https://developer.mozilla.org/en-US/docs/Web/CSS)، خصوصًا التركيز المرئي وتقليل الحركة وخصائص RTL. استُخدمت بنية الأقسام والموارد في [Reading Rockets](https://www.readingrockets.org/) و[مكتبة نيويورك للأطفال](https://www.nypl.org/education/kids) كمرجع للمحتوى والتسلسل دون نسخ أي أصل أو علامة. أمكن استخراج الصفحتين، لكن العرض المباشر في المتصفح واجه صفحات حماية/تحميل، لذلك لا ندّعي مقارنة بصرية كاملة للموقعين. لم يُستخدم Copilot: لم تكن أداة اقتراح متاحة في بيئة CLI، ولم ننسب إليه التعديل.

ظهرت قبل التغيير تحذيرات متصفح تخص ملفات ارتباط خدمة الصور وقفل جلسة Supabase؛ لم تتغير أنظمة الجلسات أو الخدمة الخلفية في هذا العمل.

## الرجوع

التغيير معزول في ملف CSS جديد ورابط واحد داخل رأس `index.html`، مع اختبار حماية. يمكن الرجوع بإلغاء commit هذا التغيير (`git revert`) دون لمس البيانات، أو حذف رابط `reader-theme.css` لإيقاف الطبقة وحدها. حافظنا على `.nojekyll` وآلية GitHub Pages الحالية.
