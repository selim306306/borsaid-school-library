# مركز تشغيل المكتبة والأتمتة

## ما يعمل في المصدر المحلي

1. **الفحص التشغيلي للقراءة فقط:** يعرض اكتمال إعداد المكتبة والفروع والعناوين والنشر، وأعداداً إجمالية للنسخ والإعارات والحجوزات. يوصي بفتح القسم المناسب ولا يغيّر سجلاً.
2. **المساعد الذكي — ملخص الإدارة:** خيار عند الطلب للمالك أو المسؤول فقط. يقرأ الخادم أعداداً وإعدادات مجمعة عبر جلسة وصلاحية المكتبة، ثم يرسل تلك الأعداد فقط إلى Gemini لتلخيصها واقتراح خطوات. لا تُرسل أسماء أو تفاصيل استعارة فردية، ولا ينفذ المساعد إجراءات.
3. **المساعد الذكي — إرشاد الموظفين:** يشرح وظائف الموقع والسياسات العامة؛ لا يقرأ سجلات المكتبة ولا ينفذ عمليات، ويتطلب موافقة مستقلة قبل إرسال نص كل سؤال إلى Gemini. التفاصيل في `docs/GEMINI_SETUP_AR.md`.
4. **المساعد الذكي للزوار عبر الموقع:** يجيب بالعربية عن المعرفة العامة، ويشرح استخدام الموقع ويبحث في الفهرس العام المنشور عند السؤال عن المكتبة. تعتمد معلومات المكتبة وكتبها وفروعها وخدماتها وأخبارها على المصادر المنشورة فقط؛ لا يتصفح المساعد الإنترنت ولا يتحقق لحظيًا. تُرسل الأسئلة العامة تلقائيًا إلى Qwen عبر Groq على الخطة المجانية عند توافر الإعداد، بعد إفصاح واضح في الواجهة؛ وإلا يستخدم الرد المحلي.
5. **متابعة سؤال عبر المساعد الذكي:** تُرسل الأسئلة العامة تلقائيًا إلى Qwen عبر Groq بالإعداد المجاني نفسه. تُحفظ التذكرة والرد الخاص لصاحبها برمز وصول عشوائي؛ وقد يصل السؤال والرد إلى مدير الموقع عبر Telegram. تُحجب المعلومات الشخصية أو الحساسة محليًا؛ لا ترسلها.

لا تعمل أدوات لوحة الموظفين في الخلفية عند إغلاق الصفحة. أما إرسال سؤال الزائر فيتم على الخادم عند الطلب، ضمن حد استخدام، ولا يحتاج بقاء لوحة الموظفين مفتوحة.

## Telegram والرسائل

المساعد الذكي عبر بوت `@PortSaidSchoolLibrariesBot` يجيب تلقائيًا عن الأسئلة العامة المنشورة باستخدام Qwen عبر Groq عند توافر إعداد الخطة المجانية، ولا يطلب موافقة لكل رسالة؛ ويعرض إفصاح الخصوصية عند `/start`. لا يرسل سؤال Telegram مباشرةً إلى المالك، ولا يحفظ الموقع نص محادثة Telegram. عند تعذّر الرد، يوجّه المستخدم إلى نموذج المساعد الذكي للمتابعة الخاصة؛ وقد تصل أسئلة نموذج الموقع إلى المدير عبر Telegram. يمكن للمالك الرد على تذكرة الموقع بالصيغة `/reply رمز_السؤال نص_الرد`، ويظهر الرد في صفحة صاحب السؤال فقط.

يجب أن تبقى بيانات البوت وأسراره في إعدادات الخادم، لا في المستودع أو الواجهة. لا تُرسل رموز التذاكر أو الوصول إلى Gemini. لا ينفذ Gemini عمليات أو يغيّر أو ينشر أو يحذف سجلاً.

## حدود الخصوصية والتشغيل

- يعرض الموقع إفصاحًا واضحًا، وتُرسل الأسئلة العامة تلقائيًا عبر Groq/Qwen عند تهيئة الخطة المجانية؛ لا يُحفظ اختيار موافقة في المتصفح. قناة Telegram تعرض إفصاح `/start` وتجيب تلقائيًا دون طلب موافقة لكل رسالة.
- لا يملك المساعد الذكي للزوار وصولاً إلى جداول الطلاب أو المستعيرين أو الإعارات الفردية. تُحجب الأنماط الشائعة للبريد والهاتف والأرقام الطويلة ومعرفات السجلات وبيانات الدخول قبل إرسال السؤال، ويُحذف النص الأصلي عند اكتشافها. تحذر الواجهة كذلك من كتابة أي اسم أو بيانات شخصية أو سرية.
- حد الإرسال الحالي 3 أسئلة لكل عنوان IP خلال 10 دقائق في ذاكرة الوظيفة؛ قد تختلف هذه الذاكرة بين نسخ Edge. راقب الاستخدام والتكلفة، ويمكن تغيير الحد ضمن وظيفة `visitor-questions`.
- نتائج الفهرس المنشورة معلومات عامة قد تتغير؛ لا يُعامل الرد كتأكيد نهائي للإتاحة أو ساعات العمل.
- لا توجد جدولة يومية/أسبوعية أو تنبيهات بريد/SMS/واتساب أو تنبيهات تشغيلية للموظفين.
