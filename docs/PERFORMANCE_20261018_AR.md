# تحسين تحميل الموقع كله

يعالج هذا التعديل تحميل الصفحة العامة ككل، لا أسماء المكتبات وحدها. لا يغيّر المحتوى أو الصور أو بيانات قاعدة البيانات أو صلاحياتها، ولا يؤجل وظائف الأقسام إلى زيارة لاحقة.

## ما تغيّر

- جُمعت ملفات CSS المحلية الخمسة والعشرون في `site-bundle.css`، بالبايتات نفسها وبترتيب التعاقب الأصلي. تبقى الملفات الأصلية مصدر التعديل؛ لا تعدّل الحزمة يدويًا. أصبح طلب التنسيق المحلي الحاجب للرسم واحدًا بدل 25؛ يبقى طلب Google Fonts كما كان.
- أصبح تحميل `external-reading-books.json` و`external-catalog-records.json` مشتركًا بين قسم القراءة وشريط التحديثات وملخص الأعداد: طلب واحد وتحليل JSON واحد لكل ملف ولكل زيارة، بدل تكرار الملف الكبير ثلاث مرات وملف الفهرسة مرتين. لا يخزن هذا التحسين البيانات بين الزيارات، ويحافظ على `cache: no-store` و`credentials: same-origin`، ويحذف الطلب الفاشل من الذاكرة للسماح بإعادة المحاولة.
- لم تتغير مكتبة Supabase أو إعدادات العملاء أو آلية المصادقة أو الصور أو جودتها. لم يُستخدم دخول موظفين أو بيانات طلاب أو مستعيرين.

## الصيانة والتحقق

تحدد `scripts/stylesheets.json` ترتيب ملفات التنسيق. ينفذ `node scripts/version-assets.mjs` توليد الحزمة تلقائيًا قبل احتساب بصمات الموارد، ويتحقق `--check` من حداثتها دون كتابة. لا تغير ترتيب القائمة إلا في مهمة تصميم مقصودة.

```sh
node scripts/version-assets.mjs
node scripts/version-assets.mjs --check
node --test tests/*.test.mjs president-banner.test.mjs
```

تشمل الاختبارات الجديدة تطابق قواعد CSS الأصلية كاملة وترتيبها، ومنع تكرار طلبات القراءة، وفصل أدوات fetch في الاختبارات، وإعادة المحاولة بعد الفشل، وعدم تعديل بيانات JSON الخام أثناء التعقيم. تُختبر التبويبات والبانر وحوار المساعد وRTL في Playwright دون إرسال نماذج أو دخول الموظفين.

قياسات الأداء خارج المستودع في محاكاة Chromium لهاتف 390×844 وكثافة 2، تنزيل 1.6 ميغابت/ثانية وزمن شبكة 150 مللي ثانية وإبطاء معالج 4×. تُكرر الزيارة الباردة ثم الدافئة ثلاث مرات في سياقات منفصلة، مع نافذة رصد ثابتة 25 ثانية لرؤية الموارد غير المتزامنة. هذه محاكاة وليست قياسًا للهاتف الحقيقي أو لشبكات مصر. لا يُساوى حدث `load` بجاهزية كل بيانات القراءة التي تُجلب لاحقًا؛ يُرصد اكتمالها منفصلًا.

## ما يبقى خارج التحكم في هذا التعديل

تظل استجابة GitHub Pages وانتشار النشر وكاش HTML، وGoogle Fonts، وسلسلة esm.sh/Supabase، والصور الخارجية واستجابة مصادر الأخبار متفاوتة حسب الشبكة والخدمة. فشل صورة مصدر خارجي بسبب سياسة المتصفح لا يُصلح بتغيير بيانات الموقع أو صلاحياته. لا يَعِد التعديل باختفاء كل تأخير أو بتحديث صفحة قديمة مفتوحة فورًا.

## التراجع

استخدم `git revert` لالتزام هذا التحسين ثم انشر `main`. يعيد ذلك روابط CSS والاستيرادات المتوافقة معًا؛ لا يتطلب التراجع أي تغيير في قاعدة البيانات. عند أي تعديل بعد التراجع أعد تشغيل أداة إصدارات الموارد قبل الالتزام.
