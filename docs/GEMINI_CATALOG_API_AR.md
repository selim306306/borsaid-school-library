# ملاحظات توثيق Gemini لمساعد الفهرسة

- يتيح توثيق [Gemini Structured Outputs](https://ai.google.dev/gemini-api/docs/structured-output) تقييد حقول JSON، ويذكر `enum` ضمن خصائص السلاسل. يستخدم المصنف هذه الخاصية لقصر اقتراح ديوي على الفئات الرئيسية المحددة، مع تحقق إضافي من التطبيق للخادم.
- يتيح توثيق [Gemini Image Understanding](https://ai.google.dev/gemini-api/docs/image-understanding) إدخال بيانات الصور المضمنة بصيغة base64 مع نوع MIME؛ يضغط المتصفح صورة الغلاف ويحوّلها إلى JPEG قبل الطلب.
- واجهة الصورة هنا تعمل بعد موافقة منفصلة، ولا ترفع صورة إلى تخزين الموقع؛ ترسل بيانات الصورة ضمن طلب المصنف الخادمي إلى Gemini، ولا يعيد المصنف تخزينها.
- المخرجات—سواء استخراج عنوان الغلاف أو رقم ديوي—مقترحات أولية يجب أن يراجعها أمين المكتبة قبل حفظ السجل.
