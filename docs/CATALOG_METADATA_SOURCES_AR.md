# مصادر مساعد فهرسة الكتب

## تصنيف ديوي العشري

- موجز OCLC الرسمي لتصنيف ديوي العشري: <https://www.oclc.org/content/dam/oclc/dewey/resources/summaries/deweysummaries.pdf>
- يقسم DDC المعرفة إلى عشر فئات رئيسية (000–900)، ثم أقسام وفروع أكثر تحديداً؛ والرقم التفصيلي ينبغي مراجعته وفق جداول التصنيف المعتمدة في المكتبة.
- يستخدم الموقع الفئات الرئيسية لإرشاد أمين المكتبة، ويطلب مراجعة الاقتراح الآلي قبل الحفظ. يظل الرقم العام المحلي مستقلاً عن رقم ديوي وعن ISBN.

## بيانات الكتاب من الفهارس العامة

- توثيق Google Books API: <https://developers.google.com/books/docs/v1/using>
  - بحث المجلدات عبر `https://www.googleapis.com/books/v1/volumes?q=isbn:<ISBN>` أو مصطلحات العنوان.
  - قد تتضمن الاستجابة العنوان والمؤلفين ومعرّفات الطبعة والفئات ورابط المعلومات. لا يلزم تسجيل دخول للبحث، لكن حدود الطلبات قد تتغير.
- توثيق Open Library Search API: <https://openlibrary.org/dev/docs/api/search>
  - يدعم البحث عبر ISBN أو العنوان والمؤلف، وإرجاع حقول محددة مثل العنوان والمؤلفين والموضوعات والسلسلة عند توفرها.
  - تختلف تغطية البيانات بين الطبعات؛ لا يخترع الموقع قيمة للسلسلة إذا لم يجدها المصدر.

## الخصوصية والمراجعة

- يقرأ مسح ISBN الباركود داخل المتصفح عبر الكاميرا، ولا يرفع صورة أو فيديو.
- عند طلب جلب البيانات، يُرسل ISBN أو نص العنوان إلى فهارس الكتب المذكورة للبحث.
- لا تُرسل بيانات الكتاب إلى Gemini إلا بعد تفعيل موافقة صريحة في النموذج، ويُستخدم ذلك لاقتراح فئة ديوي رئيسية واحدة فقط؛ يجب على أمين المكتبة مراجعة النتيجة.
- لا تُجلب أو تُعبّأ أرقام المكتبة العامة أو بيانات النسخة/الفرع/موقع الرف من الإنترنت؛ فهي معلومات محلية يحددها الموظف.
