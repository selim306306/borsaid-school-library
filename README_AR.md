# تحديث واجهة مكتبات بورسعيد المدرسية

## الرفع إلى GitHub

1. فكّ ضغط الحزمة.
2. افتح المستودع `selim306306/borsaid-school-library` على الفرع `main`، وارفع الملفات الخمسة التالية إلى **جذر المستودع** (من دون إنشاء مجلد فرعي):
   - استبدل: `index.html` و`app.js` و`open-books-live.js`.
   - أضف: `library-profiles.css` و`open-books-reader.css`.
3. أبقِ ملفات PDF الثلاثة والأخبار والأرشيف وسائر الملفات كما هي. لا ترفع هذا الملف الإرشادي إلى الموقع إن لم ترغب في ظهوره ضمن المستودع.

المسارات داخل الحزمة هي مسارات الجذر نفسها، وروابط الأنماط والبرامج النصية في `index.html` تشير إليها مباشرة.

## ما يتضمنه التحديث

- نموذج ملف المدرسة للمالك: الاسم الرسمي، الإدارة التعليمية، أمين/أخصائي المكتبات، شعار المدرسة وشعار المحافظة، مع حفظ مستقل لكل مدرسة وخيارات نشر صريحة.
- إخفاء تبويب «المكتبات» العام ما لم تتوفر ملفات مدارس أو فروع منشورة.
- قسم قراءة يعرض الكتب المتاحة نفسها في قارئ PDF داخل الصفحة، مع بحث عربي في العناوين والموضوعات وروابط المصدر والترخيص؛ ويظل البحث الفهرسي الاختياري ثانوياً.
- روابط لبنك المعرفة المصري، ومجموعات ACO العربية، ومستودع مكتبة الإسكندرية DAR، ومكتبة قطر الرقمية. تفتح الموارد لدى الجهات الأصلية، مع توضيح اختلاف الإتاحة والحقوق.

هذه الحزمة **للواجهة فقط** ولا تحتوي ترحيل Supabase أو بيانات مدرسة مفترضة أو أسرارًا أو مفتاح خدمة `service_role`. يحتفظ `app.js` بمفتاح Supabase العام القابل للنشر الموجود أصلًا في الواجهة، وهو مطلوب لاتصال الموقع ولا يمنح صلاحيات الخدمة. ترحيل ملف المدرسة منفصل ويُدار عبر منصة Supabase.
