يشمل سجلات المستعيرين والإعارة؛ ملف حساس، متاح لمالك المكتبة فقط.

هذا تصدير تشغيلي وليس نسخة PostgreSQL كاملة. النسخ التلقائية اليومية لدى Supabase متاحة لخطط Pro وTeam وEnterprise؛ أُرفق إعداد GitHub Actions آمن للنسخ الخارجية بعد إضافة الأسرار، ولم يُفعّل بعد.
