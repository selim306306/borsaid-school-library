حدود الربط والحقوق

هذه وصلات خارجية فقط؛ لا ننسخ الكتب أو ندمج نتائجها في فهرس بورسعيد. استعارة Open Library تتطلب حساباً لدى المصدر، وإتاحة Google Books تتبع حقوق العنوان والبلد. WorldCat فهرس مقتنيات لا قارئ؛ انتهى دعم Search API 1.0 في 2024، والوصول الحالي يتطلب اشتراكات مؤسسية لدى OCLC، لذا نعرض رابطاً خارجياً فقط. تفاصيل OCLC الرسمية ↗تفتح في موقع خارجي لا نستضيف نصاً إلا بترخيص يسمح بذلك.

ابحث في الأوراق والدوريات التعليمية

بيانات بحثية من فهرس عالمي؛ يعرض هذا البحث السجلات التي يصنفها OpenAlex مفتوحة الوصول، مرتبةً بالأحدث.

موضوعات مقترحة:

تُرسل عبارة البحث مباشرة إلى OpenAlex عند البحث، وتُضاف إلى رابط ERIC وتُرسل إليه فقط عند فتحه. لا يحفظ هذا الموقع عبارة البحث؛ وقد تعالج الخدمات الخارجية الطلب وفق سياساتها. العناوين والمؤلفون وسجلات الوصول بيانات خارجية نعرضها كنص فقط.

اكتب موضوعاً لبدء البحث؛ لا تُحمّل نتائج تلقائية أو محفوظة.

قاعدة متخصصة بموارد التعليم: ERIC

إن أردت توسيع البحث، افتح قاعدة ERIC الرسمية ثم راجع خيار النص الكامل وشروط كل سجل بنفسك.
