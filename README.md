# مكتبات بورسعيد المدرسية

بوابة عربية باتجاه RTL لاكتشاف الكتب العامة وإدارة تشغيل الفروع. الواجهة مبنية كملفات ثابتة مناسبة لـ GitHub Pages، وقاعدة البيانات المستهدفة هي مشروع Supabase الجديد `borsaid-school-library` (`eahptkwvjcnixlzlyznh`). لا يستخدم هذا المشروع المستودع السابق ولا يعدّل تطبيق Android أو ملفاته.

## ما أُنجز في النسخة الحالية

- فهرس عام يبحث بالعنوان والمؤلف والرقم العام والتصنيف، مع مرشح فرع/الإتاحة وصفحات نتائج.
- مساعد زوار محلي أعلى الصفحة يشرح المكتبة والإعارة والقراءة ويبحث في الفهرس العام المنشور فقط؛ لا يرسل أسئلة الزوار إلى Gemini.
- معلومات الفروع لا تظهر إلا إذا نُشرت المكتبة والفرع والسجل صراحةً.
- إعداد نشر المكتبة متاح للمالك/المسؤول من لوحة الفروع مع تأكيد قبل إظهار المكتبة للعامة؛ الفهرس العام لا يخترع بيانات عند خلو القاعدة.
- مركز تشغيل للقراءة فقط يراجع التأسيس والعدادات، مع ملخص Gemini مجمّع عند الطلب للمالك/المسؤول؛ لا يغيّر سجلات ولا يرسل تنبيهات. راجع `docs/AUTOMATION_SETUP_AR.md`.
- ذاكرة محلية لآخر نتيجة عامة فقط مع تنبيه أنها قديمة؛ لا يوجد حفظ عمليات الموظفين دون اتصال.
- تسجيل دخول للموظفين فقط، بلا إنشاء حساب عام، وربط الصلاحيات بعضوية كل مكتبة.
- تعيين/استعادة كلمة مرور الموظف عبر رابط Supabase آمن؛ إعداد إعادة التوجيه موضح في `docs/PASSWORD_SETUP_AR.md`.
- إدخال العناوين والنسخ ومواقع الرف والدولاب وتعديلها؛ حفظ العنوان مع أول نسخة في معاملة واحدة، والنشر العام اختيار صريح.
- تسجيل المستعيرين والزوار بموافقة صريحة، وإعارة/إرجاع ذرية وتجديد حتى مرتين؛ لا تُرفع صور ولا بيانات حيوية.
- جرد موثق للموجود/المفقود/التالف، حالات صيانة واستبعاد، تخصيص تلقائي للحجوزات عند توفر النسخ، وتقارير للإعارات والمتأخرات.
- إدارة عضويات متعددة المكتبات بأدوار مفصولة، وقائمة انتظار، وطلبات تداول بين مكتبتين بحالات انتقال مضبوطة؛ استقبال الطلبات يتطلب موافقة منفصلة عن نشر المكتبة للعامة.
- تصدير CSV للجرد، وتصدير تشغيلي JSON حساس لمالك المكتبة فقط؛ كلاهما ليس نسخة PostgreSQL كاملة.
- سجل تدقيق لا يحتفظ بمحتوى بيانات المستعير؛ الجداول الخاصة وعمليات الكتابة محمية بـ RLS وRPC مقيدة الدور.

## التشغيل محلياً

1. شغّل خادماً ثابتاً من مجلد المشروع، مثلاً: `python3 -m http.server 4173`.
2. افتح `http://localhost:4173`.
3. الملف `app.js` يحتوي رابط Supabase ومفتاحاً من نوع **publishable** صُمّم ليُستخدم في المتصفح. لا تضف `service_role` أو كلمة مرور أو مفتاح Gemini إلى هذا المستودع.

النشر المقترح بعد مراجعة واعتماد صاحب الحساب: مستودع عام مستقل `selim306306/borsaid-school-library` وصفحة GitHub Pages على `https://selim306306.github.io/borsaid-school-library/`. اسم `selimorg` يطابق مؤسسة Supabase في هذا الإعداد، وليس مالكاً متاحاً على GitHub بالحساب المتصل.

## قاعدة البيانات

- جميع الهجرات الثماني المسجلة على المشروع موجودة محلياً في `supabase/migrations/` بالترتيب الزمني نفسه: المخطط الأساسي، تشديد الأمان، سير العمل الذري للكتالوج، الجرد والعضويات، تخصيص الحجوزات وتدفقات الإعارة والنقل، فهارس الأداء وسياسات القراءة، ثم تفعيل المشاركة الاختيارية بين المكتبات.
- الجداول تشمل المكتبات والفروع والعضويات والعناوين والنسخ والمستعيرين والزوار والإعارات والحجوزات وطلبات النقل وسجل التدقيق.
- مفتاح Supabase المنشور ليس سراً. الأمان يعتمد على RLS وسياسات العضوية؛ لا يوجد endpoint عام للكتابة أو تسجيل موظفين.
- جميع المكتبات والفروع والسجلات تبدأ غير منشورة. صفحة البحث لا تعرض شيئاً حتى ينشر المسؤول بيانات صحيحة.
- بعد التطبيق، أنشئ أول مستخدم وفهرس مكتبة باستخدام `docs/FIRST_ADMIN_AR.md`.

## ما لم يُفعّل بعد

- لا توجد بيانات كتب أو فروع أو حسابات أو عضويات تجريبية في قاعدة المشروع الجديدة.
- الدعوات الواردة في الواجهة لها Edge Function محلية آمنة، لكنها لم تُنشر بعد؛ تتطلب إعداد نطاق الموقع وعنوان إعادة التوجيه بعد اعتماد النشر. راجع `docs/PASSWORD_SETUP_AR.md` لتفعيل عنوان تعيين كلمة المرور.
- مساعد Gemini للموظفين والمدير موجود في المصدر المحلي، لكنه غير مفعّل حتى يضبط مالك Supabase الأسرار وينشر الوظيفة. الدردشة لا تقرأ سجلات المكتبة؛ ملخص المدير يرسل أعداداً مجمعة فقط. راجع `docs/GEMINI_SETUP_AR.md`.
- مساعد الزوار يعمل محلياً من دليل الصفحة والفهرس المنشور؛ الموقع لا يستضيف نصوص الكتب حالياً ولا يعرض أسماء العاملين غير المنشورة.
- مركز التشغيل يعمل داخل لوحة الموظف عند الطلب فقط؛ لا توجد جدولة خلفية أو رسائل Telegram أو بريد/SMS مفعّلة. تكامل Telegram اختياري ويتطلب موافقة وإعداد أسرار خادمية لاحقاً.
- ملف CSV وملف JSON التشغيلي ليسا نسخة PostgreSQL كاملة. سير GitHub Actions للنسخ مشفر وموجود محلياً، لكنه معطل حتى يضيف المالك متغيرات وأسراراً خارج الكود وفق `docs/BACKUP_SETUP_AR.md` ويضبط `BACKUP_ENABLED=true`.
- تخزين صور الزوار غير مفعّل. لا تُرفع صور طلاب أو بيانات وجه/بصمة.
- الطلبات المتبادلة تُسجّل وتُدار بين المكتبات؛ لا توجد مزامنة تلقائية مع فهارس خارجية أو رسائل بريد/SMS للحجوزات والنقل.

## مبادئ الاستلهام

تغطي المراجعة ستة أنظمة في `docs/PRODUCT_NOTES_AR.md`: Koha وLibib وFollett Destiny وAlexandria وOCLC WorldCat Discovery وBook Systems Atriuum. استُخدمت أنماط الفهرسة والإعارة وتعدد المواقع والتقارير لتوجيه تدفقات أصلية؛ لم تُنسخ شفرة أو هوية أو صور الأنظمة.
